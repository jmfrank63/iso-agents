# Plan 01-01: Worker scaffold — config, envelope, switch router, health endpoint

<objective>
Stand up the Phase 1 foundation: a TypeScript Cloudflare Worker that type-checks clean
(`tsc --noEmit`), dry-run bundles clean with zero Node builtins (RUN-03), boots under real
workerd via `wrangler dev` with no Cloudflare account or API tokens (RUN-01), and serves
`GET /healthz` with the uniform JSON envelope and runtime-identity payload (RUN-02). Ships
the four-route switch skeleton (404/405/501 structured errors), the in-memory run-registry
seam with status enum, `.dev.vars.example` so later-phase config plumbing never changes
shape, and a README stub. Test harness lands in wave 2 (01-02).
</objective>

## Locked decisions this plan implements (from 01-CONTEXT.md)

- **Envelope**: every response is `{"ok":true,"data":{...}}` or
  `{"ok":false,"error":{"code":string,"message":string,"detail"?}}` — including health.
- **Router**: plain switch on `` `${method} ${pathname}` `` — no framework.
- **Config**: typed `Env` interface in `src/index.ts`; `.dev.vars` (gitignored) for local
  values; `.dev.vars.example` (committed) documents every var now.
- **Logging**: `console.*` with step prefix (`[worker]` in Phase 1) + flat timing fields.
- **Test harness (wave 2)**: vitest + `@cloudflare/vitest-plugin` — this plan only installs
  the devDependency and leaves the `test` script wired; config + tests are 01-02.

## Non-obvious decision: the two `no_nodejs_compat*` flags (binding)

`compatibility_date: "2026-09-01"` is ≥ `2026-08-04`, where Cloudflare turns
`nodejs_compat` AND `nodejs_compat_v2` **on by default**. Left alone, the isolate would get
a `process` global and typescript@6's `isNodeLikeSystem()` would initialize its Node `sys`
in Phase 2 — silently defeating the project's core in-isolate design (STATE.md: "Fully
hand-rolled CompilerHost"). The scaffold therefore sets
`"compatibility_flags": ["no_nodejs_compat", "no_nodejs_compat_v2"]` — BOTH flags, per the
Cloudflare Node.js compatibility docs, is the complete opt-out. Side benefit: with
nodejs_compat off, any accidental `node:` import fails bundle resolution outright, making
the RUN-03 gate stricter (no silent unenv stubbing).

}

  create(): RunRecord {
    const run: RunRecord = { id: crypto.randomUUID(), status: "running", createdAt: new Date().toISOString() };
    runs.set(run.id, run);
    return run;
  },
  get(id: string): RunRecord | undefined {

```ts
import { runRegistry } from "./runs";

export interface Env {
  LLM_PROVIDER?: string;
  LLM_BASE_URL?: string;
  LLM_API_KEY?: string;
  LLM_MODEL?: string;
  AGENT_MAX_ITERATIONS?: string;
  SANDBOX_TIMEOUT_MS?: string;
}

const COMPATIBILITY_DATE = "2026-09-01";
const BOOT_MS = Date.now();
const INSTANCE_ID = crypto.randomUUID(); // per isolate boot; surfaces restarts

type ErrorCode =
  | "bad_request"
  | "not_found"
  | "method_not_allowed"
  | "not_implemented"
  | "internal";

type Envelope =
  | { ok: true; data: unknown }
  | { ok: false; error: { code: ErrorCode; message: string; detail?: unknown } };

function json(body: Envelope, status: number, headers?: Record<string, string>): Response {
  return new Response(JSON.stringify(body), {
    status,
    headers: { "content-type": "application/json; charset=utf-8", ...headers },
  });
}

function fail(
  status: number,
  code: ErrorCode,
  message: string,
  detail?: unknown,
  headers?: Record<string, string>,
): Response {
  const error = detail !== undefined ? { code, message, detail } : { code, message };
  return json({ ok: false, error }, status, headers);
}

class HttpError extends Error {
  constructor(
    readonly status: number,
    readonly code: ErrorCode,
    message: string,
    readonly detail?: unknown,
  ) {
    super(message);
  }
}

// Pre-wired for Phase 2/4 POST routes (400 bad_request on malformed JSON).
// Phase 1 has no implemented POST body route, so this is unexercised by tests.
async function parseJsonBody(request: Request): Promise<unknown> {
  try {
    return await request.json();
  } catch {
    throw new HttpError(400, "bad_request", "request body is not valid JSON");
  }
}

// Lazy-init seam: Phases 2-3 fill typechecker/sandbox identities; /healthz stays fast.
export function getRuntimeInfo() {
  return {
    // Best-effort workerd version: workerd has no in-band version API, so
    // navigator.userAgent is the only in-band signal (tests assert non-empty).
    workerd: navigator.userAgent,
    compatibility_date: COMPATIBILITY_DATE,
    typechecker: "unloaded", // Phase 2: pinned pure-JS typescript version
    sandbox: "unloaded", // Phase 3: quickjs variant id
    instanceId: INSTANCE_ID,
    uptime_s: Math.floor((Date.now() - BOOT_MS) / 1000),
    userAgent: navigator.userAgent, // raw signal behind the `workerd` best-effort above
  };
}

const KNOWN_PATHS: Record<string, string> = {
  "/healthz": "GET",
  "/agent/run": "POST",
  "/typecheck": "POST",
};

export default {
  async fetch(request: Request, _env: Env, _ctx: ExecutionContext): Promise<Response> {
    const started = performance.now();
    const { method, pathname } = new URL(request.url);
    const label = `${method} ${pathname}`;
    const respond = (res: Response): Response => {
      console.log(`[worker] ${label} -> ${res.status} (${(performance.now() - started).toFixed(1)}ms)`);
      return res;
    };
    try {
      switch (`${method} ${pathname}`) {
        case "GET /healthz":
          return respond(json({ ok: true, data: { status: "ok", runtime: getRuntimeInfo() } }, 200));
        case "POST /agent/run":
        case "POST /typecheck":
          return respond(fail(501, "not_implemented", `${label} is registered but not implemented yet`));
        default: {
          if (method === "GET" && pathname.startsWith("/agent/run/")) {
            const id = pathname.slice("/agent/run/".length);
            const run = runRegistry.get(id);
            if (run === undefined) {
              return respond(
                fail(404, "not_found", `run ${id} not found`, {
                  id,
                  hint: "in-memory store; isolate restart clears it",
                }),
              );
            }
            return respond(json({ ok: true, data: run }, 200));
          }
          const allowedMethod = KNOWN_PATHS[pathname];
          if (allowedMethod !== undefined) {
            return respond(
              fail(405, "method_not_allowed", `${label} not allowed; use ${allowedMethod} ${pathname}`, undefined, {
                allow: allowedMethod,
              }),
            );
          }
          return respond(fail(404, "not_found", `no route for ${label}`));
        }
      }
    } catch (err) {
      const status = err instanceof HttpError ? err.status : 500;
      const code = err instanceof HttpError ? err.code : "internal";
      const message = err instanceof Error ? err.message : String(err);
      const detail = err instanceof HttpError ? err.detail : { instanceId: INSTANCE_ID };
      console.error(`[worker] ${label} failed:`, err);
      return respond(fail(status, code, message, detail));
    }
  },
} satisfies ExportedHandler<Env>;
```

Key points: default export is the fetch handler (ESM-format worker — plugin prerequisite);
`json()`/`fail()` centralize the envelope so later phases never negotiate format; all four

A prototype of an AI coding agent that lives entirely inside a Cloudflare workerd isolate:
