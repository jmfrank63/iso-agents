# Plan 03-01: Sandbox core — pinned quickjs deps + committed .wasm copy, pure guardrail pieces, QuickJsSandboxRuntime

<objective>
Build the Phase 3 core: generated JS executes inside QuickJS-WASM within the same workerd
isolate (SAND-01) behind a `SandboxRuntime` interface (seam symmetry with `Typechecker`),
with every guardrail in place before any guest runs — wall-clock interrupt deadline
(SAND-02), memory limit + hard-capped stack, fresh single-use contexts with dispose
discipline (SAND-04), console-only guest surface (SAND-03), and a guest-side assertion
harness returning `{name, passed, error?}`.

**This plan implements the 03-RESEARCH corrections over 03-CONTEXT's locked defaults —
three locked decisions were empirically superseded by the /tmp/qjs-spike:**
1. **Variant**: NOT singlefile-browser (DEAD on workerd: `CompileError: Wasm code
   generation disallowed by embedder` at instantiation). Use
   `@jitl/quickjs-wasmfile-release-sync@0.32.0` + `newVariant(variant, {wasmModule})`
   with a project-local copy of the artifact (`src/sandbox/quickjs.wasm`, ~491 KB,
   committed) — wrangler's default CompiledWasm rule covers `**/*.wasm` for project files
   and does NOT reach `node_modules/`, hence the copy. No `rules` entry is added
   (research gotcha 12: `CompiledWasm` is a built-in default; `"type": "Wasm"` fails
   config parsing outright). Bundle delta ≈ +608 KiB raw / +254 KiB gzip (not CONTEXT's
   +3.1 MB estimate).
2. **Stack size**: 64 KiB default (env-overridable), HARD-CAPPED at 128 KiB in code —
   NOT CONTEXT's 1 MiB. At 1 MiB/320 KB the native WASM stack overruns first: host gets
   an uncatchable `RangeError` and `context.dispose()` then ABORTS (`list_empty(&
   rt->gc_obj_list)`) — the poison reproduced. ≤128 KB gives a catchable
   `InternalError: stack overflow` and clean dispose (research rows 7/8).
3. **Deadline mechanism**: wall-clock `performance.now()` INSIDE the interrupt handler —
   NOT the CONTEXT counter-primary decision. Research proved `performance.now()` advances
   inside the handler during sync guest execution (500 ms deadline fired at 502 ms wall);
   `Date.now()` freezing does not apply to handler code. The op counter stays as a cheap
   secondary backstop.
Also research-corrected: the harness is injected as GUEST-SIDE SOURCE (`context.throw()`
from host functions does not propagate — a host-function harness recorded a failing
assertion as PASSED), and `dump(error)` can be `null` (null-safe stringify mandatory).
</objective>

## Locked decisions this plan implements (from 03-CONTEXT.md, as corrected by 03-RESEARCH.md)

- **Contract**: `SandboxRuntime { execute(code: string): Promise<ExecuteResult> }`;
  `ExecuteResult {status: "ok"|"error"|"timeout"|"crash", logs, tests, result?, error?, ms}`.
  `execute()` input is a JS string ONLY (Phase 4 feeds `ts.transpileModule` output).
- **Lifecycle**: WASM module = lazy singleton (loads on first execute, ~5 ms; healthz
  flips "unloaded" → identity after first execution — Phase 2 pattern); fresh
  `module.newContext()` per execution (creates a fresh runtime OWNED by the context — one
  `dispose()` frees both); dispose in `finally` wrapped in its OWN try/catch, separate
  from eval (the dispose-abort path must not mask the real cause); abort counter rebuilds
  the singleton after 3 (fresh module builds in ~3 ms).
- **Guardrails before guest code**: `setMemoryLimit` (default 64 MiB),
  `setMaxStackSize` (default 64 KiB, hard cap 128 KiB), interrupt handler with
  `performance.now()` wall-clock deadline (default 2000 ms) + op-counter backstop.
- **Guest surface**: ONLY injected `console` (log/info/warn/error host functions, dump()
  per arg handle, 8 KB soft cap). No fetch, no VFS, no host state.
- **Harness**: guest-side source — `test(name, fn)` (runs fn at registration, pushes
  `{name, passed, error?}` into `globalThis.__tests`) + chainable
  `expect(actual).toEqual()/toBeTrue()/toBeCloseTo()` + `assert(cond, msg)`; runtime reads
  `__tests` after eval via getProp + dump.
- **Async gate**: static source inspection BEFORE eval rejecting
  `/\basync\b|\bawait\b|\bPromise\b/` → `status: "error"` (documented limitation —
  conservative; promise shadowing cannot enforce sync-only, research row 12).
- **Status mapping** (research failure-mode matrix): guest JS exception incl. catchable
  `InternalError: out of memory` / `stack overflow` → `error`; `InternalError:
  interrupted` → `timeout`; host `RangeError` / dispose abort → `crash`.

## Empirically verified facts this plan relies on (03-RESEARCH.md, all [SPIKE] in real workerd)

- Variant package `.` export carries `types: ./dist/index.d.ts` (planner re-probed npm
  2026-10-12) — `import wasmfileVariant from "@jitl/quickjs-wasmfile-release-sync"`
  type-checks natively; only the `.wasm` import needs an ambient declaration.
- `performance.now()` advances in the interrupt handler; op load ≈ 1.7–2.1 calls/ms,
  linear (4× deadline counter backstop is pure paranoia).
- `module.newContext()` = fresh runtime owned by the context; one dispose tears down both.
- Memory-limit exceed (total churn AND single huge alloc) = catchable `InternalError: out
  of memory` → host `status: "error"`, dispose clean. Single huge alloc (`"x".repeat(2**28)`
  vs 64 MiB) fails in ~1 ms — the deterministic live-harness shape.
- Interrupt escape via guest try/catch is not possible (re-fires on subsequent polls).
- `dump(errorHandle)` may be `null` (built-in failure without JS exception) — synthetic
  `"internal sandbox failure"` message.
- Built-in overshoot is bounded but real (7.2 s worst observed after zero budget) — the
  20 KB source cap bounds guest attack surface.

// byte-comparing: safe as a postinstall hook (a no-op when current).
import { existsSync, mkdirSync, readFileSync, writeFileSync } from "node:fs";
import { dirname, join } from "node:path";
import { fileURLToPath } from "node:url";

const root = join(dirname(fileURLToPath(import.meta.url)), "..");
const pkgDir = join(root, "node_modules", "@jitl", "quickjs-wasmfile-release-sync");
const srcWasm = join(pkgDir, "dist", "emscripten-module.wasm");
const outWasm = join(root, "src", "sandbox", "quickjs.wasm");
const PINNED_VERSION = "0.32.0";

if (!existsSync(srcWasm)) {
  console.error(`FATAL: ${srcWasm} missing — run npm install first`);
  process.exit(1);
}
const installedVersion = JSON.parse(readFileSync(join(pkgDir, "package.json"), "utf8")).version;
if (installedVersion !== PINNED_VERSION) {
  console.error(
    `FATAL: @jitl/quickjs-wasmfile-release-sync@${installedVersion} is installed but ` +
      `src/sandbox/quickjs.wasm is pinned to ${PINNED_VERSION}. The copied .wasm must track ` +
      `the package version: bump PINNED_VERSION in scripts/copy-quickjs-wasm.mjs, re-run ` +
      `node scripts/copy-quickjs-wasm.mjs, and re-run the live sandbox harness.`,
  );
  process.exit(1);
}
mkdirSync(dirname(outWasm), { recursive: true });
const srcBytes = readFileSync(srcWasm);
const outBytes = existsSync(outWasm) ? readFileSync(outWasm) : null;
if (outBytes !== null && srcBytes.equals(outBytes)) {
  console.log(`src/sandbox/quickjs.wasm already up to date (${srcBytes.length} bytes)`);

2. **src/sandbox/limits.ts** (new file, exact content):

```ts
// Sandbox guardrail limits (SAND-02), parsed from env once per execution.
// The stack hard-cap is a CODE-LEVEL invariant: >128KiB overruns the native
// WASM stack before QuickJS's JS-level check — the host gets an uncatchable
// RangeError and context.dispose() then ABORTS (runtime poison, 03-RESEARCH
// rows 7/8). 64KiB default is the verified-safe zone; never raise the cap.
export interface SandboxLimits {
  timeoutMs: number;
  memoryLimitBytes: number;
  stackBytes: number;
}

export interface SandboxEnv {
  SANDBOX_TIMEOUT_MS?: string;
  SANDBOX_MEMORY_LIMIT_MB?: string;
  SANDBOX_STACK_KB?: string;
}

export const DEFAULT_TIMEOUT_MS = 2000;
export const DEFAULT_MEMORY_LIMIT_MB = 64;
export const DEFAULT_STACK_KB = 64;
export const MAX_STACK_KB = 128;
export const MAX_GUEST_SOURCE_BYTES = 20480;

const KIB = 1024;
const MIB = 1024 * 1024;

function parsePositiveInt(raw: string | undefined, fallback: number): number {
  if (raw === undefined) return fallback;
  const n = Number(raw);
  return Number.isInteger(n) && n > 0 ? n : fallback;
}

export function parseLimits(env: SandboxEnv): SandboxLimits {
  return {
    timeoutMs: parsePositiveInt(env.SANDBOX_TIMEOUT_MS, DEFAULT_TIMEOUT_MS),
    memoryLimitBytes:
      parsePositiveInt(env.SANDBOX_MEMORY_LIMIT_MB, DEFAULT_MEMORY_LIMIT_MB) * MIB,
    stackBytes:
      Math.min(parsePositiveInt(env.SANDBOX_STACK_KB, DEFAULT_STACK_KB), MAX_STACK_KB) * KIB,
  };
}
```

// Static sync-only source gate (documented limitation): QuickJS async
// functions bypass any global shadowing (research row 12 — shadowing the
// `Promise` global does NOT stop `async`/`await`), and pending jobs never
// run in the sync sandbox, so async guest code would silently hang. Guests
// are rejected by SOURCE INSPECTION before eval — conservative by design
// (a comment containing "async" is rejected too); that is the trade.
export const ASYNC_SOURCE_PATTERN = /\basync\b|\bawait\b|\bPromise\b/;

export function findAsyncUsage(code: string): string | null {
  const match = ASYNC_SOURCE_PATTERN.exec(code);
  return match === null ? null : match[0];
}

```ts
// Guest-side assertion harness (03-RESEARCH): injected as SOURCE in a first
// evalCode — NOT as host functions — because context.throw() from a host
// function does not propagate into the guest call stack (a host-function
// harness silently recorded a failing assertion as PASSED). test(name, fn)
// runs fn immediately at registration and records {name, passed, error?};
// the runtime reads the __tests global after the guest eval. Deliberately
// plain strings (no template literals inside) so this file stays one big
// template literal.
export const HARNESS_SOURCE = `globalThis.__tests = [];
globalThis.test = function (name, fn) {
  try {
    fn();
    globalThis.__tests.push({ name: name, passed: true });
  } catch (e) {
    globalThis.__tests.push({
      name: name,
      passed: false,
      error: e && e.name !== undefined ? e.name + ": " + e.message : String(e),
    });
  }
};
globalThis.expect = function (actual) {
  return {
    toEqual: function (expected) {
      if (JSON.stringify(actual) !== JSON.stringify(expected)) {
        throw new Error("expected " + JSON.stringify(expected) + ", got " + JSON.stringify(actual));
      }
    },
    toBeTrue: function (msg) {
      if (actual !== true) {
        throw new Error(msg === undefined ? "expected true, got " + JSON.stringify(actual) : msg);
      }
    },
    toBeCloseTo: function (expected, eps) {
      const tolerance = eps === undefined ? 1e-6 : eps;
      if (Math.abs(actual - expected) > tolerance) {
        throw new Error("expected ~" + expected + ", got " + actual);
      }
    },
  };
};
globalThis.assert = function (cond, msg) {
  if (!cond) {
    throw new Error(msg === undefined ? "assertion failed" : msg);
  }
};`;
```

  type QuickJSSyncVariant,
  type QuickJSWASMModule,
} from "quickjs-emscripten-core";

// Project-local copy of the variant artifact (wrangler's CompiledWasm rule
// does not reach node_modules/): a PRECOMPILED WebAssembly.Module, so
// instantiation needs zero runtime codegen — the workerd-legal path. The
// singlefile variant is DEAD on workerd ("Wasm code generation disallowed
// by embedder"); this wasmfile+newVariant({wasmModule}) shape is the
// live-verified replacement (03-RESEARCH).
import wasmModule from "./quickjs.wasm";
import { findAsyncUsage } from "./gate";
import { HARNESS_SOURCE } from "./harness";
import { markSandboxLoaded } from "./identity";
import {
  MAX_GUEST_SOURCE_BYTES,
  parseLimits,
  type SandboxEnv,
  type SandboxLimits,
} from "./limits";

// Seam symmetry with Typechecker (src/typecheck/index.ts): Phase 4's agent
// loop depends on this interface, never on quickjs directly.
export interface SandboxRuntime {
  execute(code: string): Promise<ExecuteResult>;
}

export interface SandboxLog {
  level: string;
  args: unknown[];
}

export interface SandboxTestResult {
  name: string;
  passed: boolean;
  error?: string;
}

// Status contract (03-CONTEXT + 03-RESEARCH failure-mode matrix):
// - "error": source evaluated, guest JS exception (incl. the catchable
//   InternalError: out of memory / stack overflow) or a pre-eval gate rejection
// - "timeout": interrupt deadline hit inside the guest (uncatchable in practice)
// - "crash": QuickJS/WASM-level host abort (host RangeError or dispose abort)
export interface ExecuteResult {
  status: "ok" | "error" | "timeout" | "crash";
  logs: SandboxLog[];
  tests: SandboxTestResult[];
  result?: unknown;
  error?: string;
  ms: number;
}

// newContext() creates a fresh runtime OWNED by the context — one dispose()
// tears both down, so single-use contexts cannot poison the module singleton
// (SAND-04). A dispose-abort (stack >128KiB class) leaks that runtime's heap
// permanently; the abort counter rebuilds the singleton after 3 (a fresh
// module builds in ~3ms — 03-RESEARCH rows 8/9).
const variant = newVariant<QuickJSSyncVariant>(wasmfileVariant, { wasmModule });
let modulePromise: Promise<QuickJSWASMModule> | undefined;
let abortCount = 0;
const ABORT_REBUILD_THRESHOLD = 3;

function getModule(): Promise<QuickJSWASMModule> {
  return (modulePromise ??= newQuickJSWASMModuleFromVariant(variant));
}

const LOG_LEVELS = ["log", "info", "warn", "error"] as const;
const MAX_LOG_BYTES = 8192; // console buffer soft cap (03-RESEARCH console capture)
const OPS_BACKSTOP_MULTIPLIER = 4; // handler ≈2.1 calls/ms measured; secondary guard only

function describeError(err: unknown): string {
  return err instanceof Error ? `${err.name}: ${err.message}` : String(err);
}

// dump(errorHandle) can be null (built-in failure without a JS exception —
// matrix row 10). Never read .name/.message unguarded.
function stringifyDump(d: unknown): string {
  if (d === null || d === undefined) return "internal sandbox failure";
  if (typeof d === "string") return d;
  if (typeof d === "object" && "name" in d && "message" in d) {
    const named = d as { name: unknown; message: unknown };
    return `${String(named.name)}: ${String(named.message)}`;
  }
  try {
    return JSON.stringify(d) ?? String(d);
  } catch {
    return String(d);
  }
}

function isInterrupt(d: unknown): boolean {
  return (
    typeof d === "object" &&
    d !== null &&
    (d as { name?: unknown }).name === "InternalError" &&
    String((d as { message?: unknown }).message ?? "").includes("interrupted")
  );
}

// Injected guest surface (SAND-03): ONLY console. No fetch, no VFS, no host
// state — guests get their injected globals + JS builtins, nothing else.
// Each level is a host function: dump() each arg handle (Errors -> {name,
// message, stack}, circulars -> "[object Object]"), dispose EVERY handle
// (VmFunctionImplementation's `this` param is type-level only — the FFI
// applies the guest args directly; no leading this-handle arrives).
function injectConsole(context: QuickJSContext, logs: SandboxLog[]): void {
  let logBytes = 0;
  const consoleObj = context.newObject();
  for (const level of LOG_LEVELS) {
    const fn = context.newFunction(level, (...argHandles: QuickJSHandle[]) => {
      if (logBytes > MAX_LOG_BYTES) {
        for (const arg of argHandles) arg.dispose();
        return;
      }
      const args = argHandles.map((handle): unknown => {
        const dumped = context.dump(handle);
        handle.dispose();
        return dumped === undefined ? null : dumped;
      });
      logBytes += args.reduce(
        (n: number, a) => n + (typeof a === "string" ? a.length : JSON.stringify(a)?.length ?? 8) + 1,
        0,
      );
      logs.push({ level, args });
    });
    context.setProp(consoleObj, level, fn);
    fn.dispose();
  }
  context.setProp(context.global, "console", consoleObj);
  consoleObj.dispose();
}

export class QuickJsSandboxRuntime implements SandboxRuntime {
  constructor(private readonly limits: SandboxLimits) {}

  async execute(code: string): Promise<ExecuteResult> {
    const t0 = performance.now();
    const logs: SandboxLog[] = [];
    const tests: SandboxTestResult[] = [];

    if (code.length > MAX_GUEST_SOURCE_BYTES) {
      return {
        status: "error",
        logs,
        tests,
        error: `guest source is ${code.length} bytes; limit is ${MAX_GUEST_SOURCE_BYTES}`,
        ms: performance.now() - t0,
      };
    }
    const asyncToken = findAsyncUsage(code);
    if (asyncToken !== null) {
      return {
        status: "error",
        logs,
        tests,
        error:
          `async execution is not supported in the sandbox (documented limitation): ` +
          `source contains "${asyncToken}"`,
        ms: performance.now() - t0,
      };
    }

    const module = await getModule();
    markSandboxLoaded();
    const context = module.newContext(); // fresh runtime + context, single use (SAND-04)
    let status: ExecuteResult["status"] = "ok";
    let error: string | undefined;
    let result: unknown;
    try {
      // Guardrails (SAND-02) BEFORE any guest code runs.
      context.runtime.setMemoryLimit(this.limits.memoryLimitBytes);
      context.runtime.setMaxStackSize(this.limits.stackBytes);
      const deadline = performance.now() + this.limits.timeoutMs;
      let ops = 0;
      // Wall-clock primary: performance.now() ADVANCES inside the interrupt
      // handler during sync guest execution (03-RESEARCH correction — the
      // counter-primary premise was stale). The op counter stays as a cheap
      // secondary backstop in case a future workerd freezes the handler clock.
      context.runtime.setInterruptHandler(
        () => performance.now() > deadline || ++ops > OPS_BACKSTOP_MULTIPLIER * this.limits.timeoutMs,
      );

      injectConsole(context, logs);
      const harnessResult = context.evalCode(HARNESS_SOURCE, "harness.js");
      if (harnessResult.error) {
        error = `harness setup failed: ${stringifyDump(context.dump(harnessResult.error))}`;
        harnessResult.error.dispose();
        status = "error";
      } else {
        harnessResult.value.dispose();
      }

      if (status === "ok") {
        const evalResult = context.evalCode(code, "guest.js", { type: "global", strict: true });
        if (evalResult.error) {
          const dumped = context.dump(evalResult.error); // may be null — matrix row 10
          evalResult.error.dispose();
          if (isInterrupt(dumped)) {
            status = "timeout";
            error = `execution exceeded the ${this.limits.timeoutMs}ms sandbox deadline`;
          } else {
            status = "error";
            error = stringifyDump(dumped);
          }
        } else {
          result = context.dump(evalResult.value); // plain JSON-able data only
          evalResult.value.dispose();
        }
      }

      // Tests registered BEFORE a guest throw still landed in __tests
      // (test() runs fns at registration) — read them for feedback. Skipped
      // on timeout: the guest aborted mid-flight; its state is not trustworthy.
      if (status !== "timeout") {
        const testsHandle = context.getProp(context.global, "__tests");
        const dumpedTests: unknown = context.dump(testsHandle);
        testsHandle.dispose();
        if (Array.isArray(dumpedTests)) {
          for (const t of dumpedTests) {
            const entry = t as { name?: unknown; passed?: unknown; error?: unknown };
            tests.push({
              name: String(entry.name ?? "(unnamed)"),
              passed: entry.passed === true,
              ...(entry.error === undefined ? {} : { error: String(entry.error) }),
            });
          }
        }
      }
    } catch (err) {
      // Host-level failure: evalCode RangeError (native stack >128KiB class)
      // or any QuickJS abort — a catchable host exception, status "crash".
      status = "crash";
      error = describeError(err);
      abortCount += 1;
    } finally {
      // dispose() can abort EVEN WHEN eval did not (matrix row 8) — guard it
      // separately so the dispose exception cannot mask the real cause.
      try {
        context.dispose();
      } catch (disposeErr) {
        status = "crash";
        error ??= `dispose: ${describeError(disposeErr)}`;
        abortCount += 1;
      }
    }
    if (abortCount >= ABORT_REBUILD_THRESHOLD) {
      modulePromise = undefined; // rebuild singleton on next execute (~3ms)
      abortCount = 0;
    }
    return {
      status,
      logs,
      tests,
      ...(result !== undefined ? { result } : {}),
      ...(error !== undefined ? { error } : {}),
      ms: performance.now() - t0,
    };
  }
}

// One runtime instance per request (limits come from per-request env); the
// WASM module singleton is shared module-level state. Env is structurally
// satisfied by the worker's Env interface.
export function getSandboxRuntime(env: SandboxEnv): SandboxRuntime {
  return new QuickJsSandboxRuntime(parseLimits(env));
}
