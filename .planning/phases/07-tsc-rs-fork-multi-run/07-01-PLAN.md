## How the worker hosts it (WASM-01/02/03 + FORK-02)

- **Import**: `import wasmModule from "./ts_rust.wasm"` — wrangler's default CompiledWasm rule
  (NO `rules` entry needed; same mechanism as `src/sandbox/quickjs.wasm`, which coexists —
  `npm run bundle:check` ships both). The import is a precompiled `WebAssembly.Module`; the
  only legal instantiation in workerd is with host-supplied imports, which the shim provides.
- **Shim**: `src/typecheck-wasm/shim.ts` is a workerd-safe TypeScript port of upstream
  `npm/wasm/core.js`: `ts_host.fs`/`fs_take` over `memfs.ts`'s in-memory map, a working WASI
  subset (`args_sizes_get`/`args_get`/`environ_sizes_get`/`environ_get`/`clock_time_get`/
  `clock_res_get`/`random_get`/`fd_write`/`fd_fdstat_get`/`fd_prestat_get`/`proc_exit`/
  `sched_yield`/`poll_oneoff`), and ENOSYS (52) stubs wired to EVERY other import the module
  actually declares (imports-driven loop, like core.js). NO Node APIs: core.js's Node-only bits
  (`worker_threads` 256 MB stacks, real fs) are deliberately not ported — the run is synchronous
  on the calling thread.
- **HELD instance per isolate (FORK-02, supersedes Phase 6's fresh-instance-per-check)**: the
  shim's `runTscHeld` keeps ONE lazy singleton `WebAssembly.Instance` (the `WebAssembly.Module`
  is compiled once at bundle load) and serves every check with a `ts_run` on it. The instance is
  recycled — dropped and re-instantiated from the same compiled module, 2–8 ms — after **50
  runs** (env-overridable via `TSCHECKER_WASM_RECYCLE_AFTER`; the live harness forces 2 to walk
  the boundary) and on **ANY throw** out of `ts_run`: a `WasiExit` there is the panic-hook exit
  (normal exits arrive as ts_run's RETURN value — 0 clean, 2 = diagnostics found, NOT an error),
  and non-WasiExit throws are the trap/RangeError class. Post-panic Rust state is undefined (a
  panic between `install_program_version` and `end_run` leaves the version bookkeeping
  mid-flight), so the instance is dropped no matter what; the next check instantiates fresh.
  Probe-measured recycle: 162 ms end-to-end including the fresh cold check.
- **The held fs is the parse-cache contract**: the held instance's `MemoryFileSystem` lives as
  long as the instance, and `memfs.ts` stamps every `writeFile`/`remove` with a fresh monotonic
  `mtimeNs`. The fork's `MultiRunHost` serves an unchanged file's parse from its stat-cache
  (path + mtime) without re-reading/re-parsing, and re-parses only files whose mtime moved — a
  CONSTANT mtime silently serves stale parses (07-RESEARCH negative control: a constant-mtime fs
  returned exit 0/[] for a TS2322 guest it had already parsed clean). Files a check no longer
  has are REMOVED from the held fs so they cannot join `include: ["*.ts"]`.
- **First-cwd freeze**: `install_os_override` runs once per instance, so the first run's cwd is
  every run's cwd (07-RESEARCH state matrix). iso-agents always checks with `cwd: "/"` +
  `-p /app` (constant), asserted by `runTscHeld`; env is pinned per instance the same way (WASI
  environ installs at instantiation), and `CASE_SENSITIVE` wins from the first request —
  iso-agents never sets the case-insensitive flag.
- **Run protocol**: request = `[cwd, flags, ...args].join("\0")` UTF-8 written via
  `ts_input(len)`; `ts_run()` executes (exit code as its RETURN value: 0 clean, 2 = diagnostics
  found); diagnostics JSON comes back from `ts_output()`/`ts_output_len()`; `proc_exit`
  surfaces as a thrown `WasiExit` — abnormal in the held flow, i.e. the recycle trigger above.
- **Libs are INSIDE the module** (embedded LZMA, decoded in-Rust) — no lib assets are vendored
  or seeded by the host. Guest files + a strict/es2022 tsconfig are synced under `/app` on the
  held fs; diagnostics fileNames are mapped back to the repo's rooted form by `mapping.ts`.
- **Flags used**: bit 0 (diagnostics JSON) only. `--watch`/`--lsp`/`--api` do not exist in the
  wasm build.
- **Cost model (07-RESEARCH, workerd)**: cold first run ≈ 0.5–1.2 s; warm held runs
  **71–123 ms** (~4–7×); held steady-state memory **62,521,344 bytes flat (runs 2–50)** vs
  ~57 MB one-shot — the second (previous) program version costs ~5.5 MB, comfortably inside the
  128 MB isolate alongside the JS heap. `runTsc` (fresh instance per call) remains in the shim
  as the Phase 6 fresh-instance path — the bench's "wasm (fresh)" leg reproduces exactly those
  semantics via a `TSCHECKER_WASM_RECYCLE_AFTER:1` boot.

## Known limits (documented, not solved — 06-CONTEXT/07-CONTEXT)

- **Stack depth**: the module links a 32 MiB in-linear-memory shadow stack
  (`-zstack-size=33554432`). With no JSPI in workerd, deep checker recursion can trap the
  instance; with the held instance the trap ALSO recycles it (recycle-on-throw), and the route
  returns the structured 500 envelope. Guests in this prototype are small.
- **Sync CPU-bound run**: spike-measured per request in workerd — cold ≈ 0.5–1.2 s, warm held
  ≈ 70–125 ms, instantiate 2–8 ms. Local `wrangler dev` does not enforce CPU limits;
  production would need a paid plan's 30 s ceiling. The prototype is local-only.
- **Fork is local**: `multi-run` @ `c1b8218339d0` exists only in the spike clone — see Rebuild
  step 3 for the recovery path if `/tmp/tsrust-spike` is gone.

```ts
// ---- held-instance runtime (FORK-02, 07-CONTEXT decision) ----
//
// ONE WebAssembly.Instance per isolate: the multi-run fork serves many
// ts_run calls per instance through its program-version flow, dropping the
// per-check cost from ~0.5-1.2 s cold to ~70-125 ms warm (07-RESEARCH).
// The compiled Module is the same bundle-load import both paths share;
// recycling = dropping the instance and instantiating a fresh one from it
// (2-8 ms; probe-measured 162 ms end-to-end incl. the fresh cold check).

// Default recycle threshold (07-CONTEXT: recycle after 50 runs). The
// factory overrides it per isolate from TSCHECKER_WASM_RECYCLE_AFTER
// (parsed in src/typecheck/selection.ts) — the live harness boots with 2
// to walk the recycle boundary over HTTP.
export const RECYCLE_AFTER_RUNS = 50;

// Module-level held state: the prepared run (imports bound to the held fs)
// + the instance + the fs itself, all keyed to the instance's lifetime —
// the fs's monotonic mtime stamps only guarantee freshness within one
// instance's lifetime, which is exactly the parse cache's lifetime.
let heldPrepared: ReturnType<typeof prepareRun> | undefined;
let heldInstance: WebAssembly.Instance | undefined;
let heldFs: MemoryFileSystem | undefined;
let heldGen = 0; // instances created so far (recycles = max(gen - 1, 0))
let heldRunsOnInstance = 0;
let heldRunsTotal = 0;
let heldEnvKey = ""; // env is installed once per instance (WASI environ)

// Per-run stdout/stderr sinks for the held instance's imports (bound once
// at instantiation; cleared at the top of every runTscHeld call).
const heldStdoutChunks: string[] = [];
const heldStderrChunks: string[] = [];

export interface HeldRunStats {
  instanceGen: number; // 0 until the first held run instantiates
  runsOnInstance: number;
  runsTotal: number;
  recycles: number;
  memoryBytes: number | null; // held linear memory; null while down
}

function dropHeldInstance(): void {
  heldPrepared = undefined;
  heldInstance = undefined;
  heldFs = undefined;
}

export function heldRunStats(): HeldRunStats {
  return {
    instanceGen: heldGen,
    runsOnInstance: heldRunsOnInstance,
    runsTotal: heldRunsTotal,
    recycles: Math.max(heldGen - 1, 0),
    memoryBytes:
      heldInstance !== undefined
        ? (heldInstance.exports as TsRustExports).memory.buffer.byteLength
        : null,
  };
}

// Sync the check's files into the held fs BEFORE ts_run: write changed/new
// files (each write stamps a fresh monotonic mtimeNs — the fork's parse-
// cache key) and REMOVE files the check no longer has (a stale guest would
// otherwise join include: ["*.ts"] and pollute the diagnostics).
function syncHeldFiles(fs: MemoryFileSystem, files: Map<string, string>): void {
  for (const [path, content] of files) {
    if (fs.readFile(path) !== content) {
      const err = fs.writeFile(path, ENCODER.encode(content), false);
      if (err !== undefined) {
        throw new Error(`runTscHeld: seeding ${path} failed: ${err}`);
      }
    }
  }
  for (const path of [...fs.files.keys()]) {
    if (!files.has(path)) fs.remove(path);
  }
}

export interface HeldRunResult extends WasmRunResult {
  instanceGen: number;
  runsOnInstance: number;
}

// One ts_run on the held singleton. recycleAfter bounds the instance's run
// count (07-CONTEXT: 50); ANY throw drops the instance regardless (see the
// header rationale — post-panic Rust state is undefined). cwd is pinned to
// "/": install_os_override runs once per instance, so the first run's cwd
// is every run's cwd (07-RESEARCH) — iso-agents always checks with
// cwd "/" + -p /app, asserted here. Env is pinned the same way (WASI
// environ is instance state, installed at instantiation).
export function runTscHeld(
  options: RunTscOptions,
  recycleAfter: number = RECYCLE_AFTER_RUNS,
): HeldRunResult {
  assertModuleShape();
  if ((options.cwd ?? "/") !== "/") {
    throw new TypeError(`runTscHeld requires cwd "/"; got ${JSON.stringify(options.cwd)}`);
  }
  const envKey = JSON.stringify(options.env ?? {});
  if (heldInstance !== undefined && heldEnvKey !== envKey) {
    dropHeldInstance(); // env changed: WASI environ is instance state
  }
  if (heldInstance !== undefined && heldRunsOnInstance >= recycleAfter) {
    dropHeldInstance(); // scheduled recycle: fresh instance, same Module
  }
  let instantiateMs = 0;
  if (heldInstance === undefined) {
    const tInst = performance.now();
    heldGen += 1;
    heldRunsOnInstance = 0;
    heldEnvKey = envKey;
    heldFs = createMemoryFileSystem();
    heldPrepared = prepareRun(wasmModule, {
      args: options.args,
      cwd: "/",
      fs: heldFs,
      env: options.env,
      stdout: (chunk) => heldStdoutChunks.push(STREAM_DECODER.decode(chunk, { stream: true })),
      stderr: (chunk) => heldStderrChunks.push(STDERR_DECODER.decode(chunk, { stream: true })),
      diagnosticsJson: options.diagnosticsJson,
    });
    heldInstance = new WebAssembly.Instance(wasmModule, heldPrepared.imports);
    instantiateMs = performance.now() - tInst;
  }
  const servedGen = heldGen;
  const fs = heldFs!;
  const prepared = heldPrepared!;
  const instance = heldInstance;
  syncHeldFiles(fs, options.files);
  heldStdoutChunks.length = 0;
  heldStderrChunks.length = 0;
  const tRun = performance.now();
  const tsRun = prepared.start(instance); // also resets the stderr accumulator
  let exitCode = SUCCESS;
  let error: unknown;
  heldRunsOnInstance += 1;
  heldRunsTotal += 1;
  try {
    exitCode = tsRun();
  } catch (thrown) {
    error = thrown;
    // RECYCLE ON ANY THROW (07-RESEARCH): a WasiExit here is the panic-hook
    // exit (normal exits arrive as ts_run's RETURN value — 0 clean, 2 =
    // diagnostics found, NOT an error — probe-proven: red guests stayed
    // warm with memory flat runs 2-50), and a non-WasiExit throw is the
    // trap/RangeError class. Post-panic Rust state is undefined (a panic
    // between install_program_version and end_run leaves the version
    // bookkeeping mid-flight), so drop the instance BEFORE reporting; the
    // local `prepared` still parses result() against the dying instance.
    dropHeldInstance();
  }
  const { exitCode: code, diagnostics } = prepared.result(exitCode, error);
  return {
    exitCode: code,
    diagnostics,
    stdout: heldStdoutChunks.join("").slice(0, 65536),
    stderr: heldStderrChunks.join("").slice(0, 65536),
    timings: { instantiateMs, runMs: performance.now() - tRun },
    instanceGen: servedGen,
    runsOnInstance: heldRunsOnInstance,
  };
}

// TscRsWasmTypechecker (WASM-02/03 + FORK-02): the real Rust checker
// (ts_goport built to wasm32-wasip1, the multi-run fork) running INSIDE the
// workerd isolate behind the same Typechecker seam as TsTypechecker. ONE
// held WebAssembly.Instance per isolate — instance-per-isolate, not
// per-check — recycled after 50 runs (or the TSCHECKER_WASM_RECYCLE_AFTER
// override) and on any error, per 07-CONTEXT. The libs are embedded in the
// module; guest files ride the shim's held fs bridge, where every changed
// file is re-stamped so the fork's parse cache reuses exactly the unchanged
// files (07-RESEARCH: warm 71-123 ms vs ~0.5-1.2 s cold; memory flat at
// 62,521,344 bytes across runs 2-50). Diagnostics arrive as ts_goport JSON
// and are mapped by ./mapping onto the exact flat shape the ts-js checker
// emits.
import { GUEST_GLOBALS_TEXT } from "../typecheck/vfs";
import type {
  TypecheckerHeldStats,
  TypecheckResult,
  Typechecker,
} from "../typecheck/index";
import { mapWasmDiagnostics } from "./mapping";
import {
  heldRunStats,
  runTscHeld,
  TS_RUST_FORK_BRANCH,
  TS_RUST_FORK_COMMIT,
} from "./shim";

// The spike-proven project config seeded into every check (06-RESEARCH
// probe requests): strict + es2022, wildcard include relative to /app.
// CLI args add --noEmit; everything else is the module's embedded default.
// `lib: ["es2022"]` mirrors the ts-js guest surface (core closure, no DOM):
// the module's default lib chain includes DOM (`var console: Console`),
// which TS2403-clashes with the seeded guest-globals.d.ts console (proven
// live, 06-02 T2). Constant across every check — tsconfig and globals are
// parse-reused by the held instance forever.
const TSCONFIG_TEXT =
  '{"compilerOptions":{"strict":true,"target":"es2022","lib":["es2022"]},"include":["*.ts"]}';

export class TscRsWasmTypechecker implements Typechecker {
  // Fork-qualified identity (FORK-01): the fork changes observable
  // behavior (one instance, many runs), so the id says so.
  readonly id = `ts-rust@${TS_RUST_FORK_BRANCH}/${TS_RUST_FORK_COMMIT.slice(0, 7)} (wasm)`;

  // Undefined -> the shim's default (RECYCLE_AFTER_RUNS = 50). The factory
  // passes the parsed TSCHECKER_WASM_RECYCLE_AFTER so the live harness can
  // force the recycle boundary over HTTP.
  constructor(private readonly recycleAfter?: number) {}

  async check(files: Map<string, string>): Promise<TypecheckResult> {
    // Repo paths are rooted ("/guest.ts"); the module's project root is
    // /app (the tsconfig home) — guests are synced one level down and
    // diagnostics are mapped back (mapping.ts) so reported files stay
    // byte-identical across checker implementations. syncHeldFiles re-
    // stamps changed files and REMOVES files this check no longer has.
    const wasmFiles = new Map<string, string>([["/app/tsconfig.json", TSCONFIG_TEXT]]);
    for (const [name, content] of files) {
      wasmFiles.set(`/app${name.startsWith("/") ? name : `/${name}`}`, content);
    }
    // Ambient globals (test/expect/assert/console): include ["*.ts"] picks
    // the .d.ts up; without this seed every test() guest drowns in TS2593
    // (same rootName lesson as the ts-js checker and the 05-01 bench).
    wasmFiles.set("/app/guest-globals.d.ts", GUEST_GLOBALS_TEXT);
    const t0 = performance.now();
    const run = runTscHeld(
      {
        files: wasmFiles,
        args: ["-p", "/app", "--noEmit"],
        cwd: "/", // first-cwd freeze: run 1's cwd is every run's cwd (07-RESEARCH)
        env: { NO_COLOR: "1" },
        diagnosticsJson: true,
      },
      this.recycleAfter,
    );
    const ms = performance.now() - t0;
    const diagnostics = mapWasmDiagnostics(run.diagnostics);
    return { ok: diagnostics.every((d) => d.category !== "Error"), diagnostics, ms };
  }

  // FORK-03 observability: instance generation, run counters, recycle
  // count and the held instance's linear-memory bytes — the /typecheck
  // endpoint surfaces this so the live harness proves reuse + recycling
  // over HTTP without touching check()'s semantics.
  heldStats(): TypecheckerHeldStats {
    return heldRunStats();
  }
}
```

```ts
// FORK-02: TSCHECKER_WASM_RECYCLE_AFTER overrides the held wasm instance's
// run-count recycle threshold (default 50 = RECYCLE_AFTER_RUNS in
// src/typecheck-wasm/shim.ts). undefined when unset/empty so the shim's
// default applies; throws honestly on garbage, same style as parseTSChecker.
export function parseTSCheckerWasmRecycleAfter(
  env?: { TSCHECKER_WASM_RECYCLE_AFTER?: string },
): number | undefined {
  const raw = env?.TSCHECKER_WASM_RECYCLE_AFTER;
  if (raw === undefined || raw === "") return undefined;
  const n = Number(raw);
  if (!Number.isInteger(n) || n < 1) {
    throw new Error(`TSCHECKER_WASM_RECYCLE_AFTER must be a positive integer; got "${raw}"`);
  }
  return n;
}
```
